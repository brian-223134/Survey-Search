# docs — 실험·평가 기록

`README.md` 는 "이 패키지가 무엇이고 어떻게 쓰는가"를 답합니다.
이 폴더는 **"무엇을 재봤고 무엇이 나왔는가"** 를 실험 단위로 나눠 기록합니다.

각 문서는 혼자 읽을 수 있게 썼습니다 — 무엇을 물었고, 어떻게 쟀고, 무엇이 나왔고,
그래서 무엇을 정했는지. **틀렸던 것도 지우지 않고 남깁니다.** 이 프로젝트에서
가장 값진 결과 중 몇 개가 "당연히 좋을 것"이 틀렸다는 발견이었습니다.

## 읽는 순서

**처음이라면** — [evaluation-setup.md](evaluation-setup.md) → [ablation-170.md](ablation-170.md).
이 둘이면 "무엇을 만들었고 얼마나 잘 되는가"에 답이 됩니다.

**코드를 고칠 거라면** — [pitfalls.md](pitfalls.md) 를 먼저 읽으세요.
열네 개 전부 실제로 밟은 것이고, 그중 몇은 두 번 밟았습니다.

**호스트에 끼울 거라면** — 함정 13·14(어댑터 배선)와 `../SURVEY-SEARCH.md` §6.
"시그니처가 맞는 것"과 "인자가 도착하는 것"은 다릅니다.

**발표하거나 설명할 거라면** — [presentation/](presentation/README.md).
같은 내용을 "무엇을 재봤는가"가 아니라 **"어떤 순서로 말해야 하는가"** 로 다시 짜 두었습니다.

**결과를 못 믿겠다면** — [determinism.md](determinism.md).
2026-08-13 이전에 뽑은 숫자는 재현되지 않습니다. 그 이유가 여기 있습니다.

## 원칙

- **실측과 추정을 구분합니다.** 실측이면 `n` 과 측정 조건을 적습니다
- **격차가 작으면 표준오차를 같이 냅니다.** 0.5%p 차이를 평균만 보고 보고하지 않습니다
- **틀린 것은 정정 이력을 남깁니다.** "무엇을 왜 잘못 봤는가"가 다음 사람에게 쓸모 있습니다

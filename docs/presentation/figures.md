## F1. 문제 — 서베이 에이전트의 구조

```
토픽 → [ 검 색 ] → 논문 집합 → [개요 생성] → [섹션 작성] → 서베이
         ↑
    dense 벡터 1방 + top-k 에서 멈춰 있음
```

## F2. 기존 구현 실태

| | AutoSurvey | SurveyForge |
|---|---|---|
| 쿼리 | 토픽 문자열 1개 → top-1200 | 멀티쿼리 union + 2단계(1500편) |
| 융합 | 없음 | union — 순위 정보를 버림 |
| 어휘 검색 | 없음 | `NotImplementedError` 스텁 |
| 재랭킹 | 없음 | 2년 시간창별 **인용수 정렬** |
| 인용 그래프 | 없음 | 없음 |

*출처: 두 레포의 검색 경로 직접 확인*

## F3. 전제 확인 — 인용수 정렬이 코퍼스의 3할을 뒤로 보냅니다

## F4. 파이프라인

```
topic
  ├─ S1  facet 분해 ──── LLM 1회(캐시) → 하위 주제 8~16개, 각 1~3 쿼리
  ├─ S2  dense 검색 ──── FAISS (gte-large-en-v1.5, 1024d, 908,819편)
  ├─ S3  어휘 검색 ────── DuckDB BM25                    [측정 후 조건부 OFF]
  ├─ S4  RRF 융합 ────── facet 내부 → facet 간, 2단
  ├─ S5  중복 제거 ────── arXiv 버전 병합 + 제목 정규화
  ├─ S6  freshness ───── 연령 정규화 인용률 백분위 + recency
  ├─ S8  스노우볼링 ───── S2 API 인용 그래프 (전방·후방)
  ├─ S8b cross-encoder ─ 재랭킹                          [측정 후 OFF]
  ├─ S7  다양성 ──────── MMR + facet 쿼터                 [측정 후 OFF]
  └─ SearchResult (papers + facets + stats)
```

## F5. 핵심 수식 셋

```
RRF        score(d) = Σ_q  1 / (k + rank_q(d)),   k = 60

freshness  citation_rate = citation_count / max(months_since_pub, 3)
           final = rrf × (1 + α·rate_percentile) × (1 + β·recency)

MMR        λ·relevance − (1−λ)·max_sim(이미 고른 것)      [끔]
```

## F6. 차별성 대조표

| | AutoSurvey | SurveyForge | **survey-search** |
|---|---|---|---|
| 쿼리 | 토픽 1개 | 멀티쿼리 union | **facet 8~16 × 표면형 1~3** |
| 융합 | — | union | **2단 RRF** |
| 어휘 | 없음 | 스텁 | **DuckDB BM25** |
| 랭킹 | 유사도 | **인용수 정렬** | **연령 정규화 인용률 백분위** |
| 인용 그래프 | 없음 | 없음 | **전방·후방 스노우볼링** |
| 계측 | 없음 | 없음 | **단계별 stats** |
| 평가 | — | — | **정답 170토픽 ablation** |

## F7. 주 결과 — 170토픽

| 설정 | R@50 | R@100 | R@500 | R@1500 | nDCG |
|---|---|---|---|---|---|
| dense only | 15.4% | 21.5% | 36.3% | 38.7% | 0.200 |
| + BM25 | 13.4% | 18.9% | 35.4% | 41.7% | 0.177 |
| + freshness | 14.0% | 20.1% | 36.4% | 41.7% | 0.217 |
| + facets | **19.0%** | **25.5%** | 43.9% | 56.9% | 0.294 |
| **+ facets, BM25 끔** | 18.6% | 25.4% | **44.4%** | **57.5%** | **0.299** |

*토픽 170개 = SurGE 정답 집합 전체, 토픽당 평균 정답 72편, `n_papers=1500`, 서베이별 날짜 컷오프*

## F8. 단계별 증분

| 단계 | R@50 | R@1500 | nDCG |
|---|---|---|---|
| → + BM25 | −2.0%p | **+3.1%p** | **−0.023** |
| → + freshness | +0.6%p | ±0.0%p | **+0.040** |
| → + facets | **+5.0%p** | **+15.2%p** | **+0.077** |

## F9. 천장 — 검색 반, 랭킹 반

| 단계 | recall |
|---|---|
| ① 코퍼스 상한 | 100.0% |
| ② 컷오프 상한 | 95.8% |
| ③ 풀 recall | **77.7%**  ← 검색 손실 18.1%p |
| ④ 최종 recall | **59.1%**  ← 랭킹 손실 18.6%p |

*토픽 16개, `facets+lexical+freshness`, 평균 후보 풀 12,134편*

## F10. 검색 손실은 깊이 부족이었다

| 쿼리당 `top_k` | 평균 후보 풀 | 풀 recall |
|---|---|---|
| 500 | 3,933 | 73.3% |
| **2,000** (기본) | 13,070 | 84.6% |
| 8,000 | 42,686 | **91.1%** |

*토픽 8개. 초록으로 도달 불가한 몫 ≈ 5%p*

## F12. facet 이 켜지면 BM25 는 아무것도 안 합니다

**토픽별 짝지은 비교** (170토픽, BM25 켬 − 끔):

| | 평균차 | 승/패 |
|---|---|---|
| R@50 | +0.40%p ± 0.29 (SE) | 60 / 48 |
| R@500 | −0.51%p ± 0.35 | 57 / 71 |
| R@1500 | −0.57%p ± 0.32 | 54 / 74 |
| nDCG | −0.0054 ± 0.0062 | 81 / 89 |

**넷 다 `|평균차| < 2×SE`** — 방향을 단정할 수 없습니다.

**대조하면 분명합니다:**

| BM25 를 켜서 얻는 R@1500 | |
|---|---|
| facet **없이** | **+3.1%p** |
| facet **있이** | **−0.6%p** (0과 구분 안 됨) |

## F13. cross-encoder 점수는 쿼리 간 비교 불가

| facet 쿼리 | 평균 점수 |
|---|---|
| rationale extraction machine reading comprehension | 0.127 |
| chain-of-thought prompting reading comprehension | **0.006** |

**20배** 차이 → "관련성"이 아니라 **"어느 facet 소속인가"로 정렬**됩니다.

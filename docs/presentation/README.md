## 한 장 요약 — 이걸 못 말하면 발표가 안 된 것

> 서베이 생성 에이전트는 전부 "찾고 → 개요 짜고 → 쓴다"인데, **첫 단계인 검색은
> dense 벡터 한 방 + top-k 에서 멈춰 있습니다.** survey-search 는 그 자리를
> **끄고 켤 수 있는 8단계**로 다시 쌓고, 각 단계가 정답 기준으로 얼마나 기여하는지
> 분리해서 쟀습니다.
>
> 정답 토픽 170개 전체에서 **R@1500 38.7% → 57.5%, nDCG 0.200 → 0.299.**
> 그런데 그 상승분은 거의 전부 **한 단계(facet 분해)** 에서 나왔고,
> **당연히 좋을 줄 알았던 세 단계는 정답 기준으로 손해였습니다.**
> 후자가 이 프로젝트의 더 중요한 결과입니다.
